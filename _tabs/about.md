### Ship database changes the way you ship code.

My name is Richard and I help engineering teams put their databases in version control, automate schema changes with CI/CD, and run cloud databases with infrastructure as code. Fewer late-night manual scripts, faster releases.

### Challenges

The database is the slowest part of your release

* **Schema changes run by hand** : Someone pastes SQL into production after hours and hopes it works. Rollbacks are improvised, and only one person knows how.
* **Environments don't match** : Dev, test, and production have drifted apart. Code that passed testing breaks in production because the schema was different.
* **Provisioning takes days** : New databases, replicas, and access requests go through tickets and click-ops in the cloud console, with no record of what changed.
