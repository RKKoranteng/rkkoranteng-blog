About

Hi, I'm Richard.

I help engineering teams put their databases in version control, automate schema changes with CI/CD, and run cloud databases with infrastructure as code. Fewer late-night manual scripts, faster releases.

Why I do this work

In too many teams, the application ships through a modern pipeline while the database still moves by hand. Schema changes get pasted into production after hours, environments drift, and provisioning waits on tickets. The database becomes the slowest part of every release.

I've spent my career on the database side of that gap, from installing and running Oracle on Linux to building self-service CI/CD pipelines that let developers ship database changes safely without waiting on a DBA. Now I help teams close the gap for good.

I also write about what I learn and share my code on GitHub.
